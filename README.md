# VERITAS

Deprem Kayıtlarının Seçimi ve Ölçeklendirilmesi (TBDY 2018 §2.5) — PyQt6
masaüstü uygulaması.

Kurulum ve kullanım ayrıntıları için [`BENIOKU.txt`](BENIOKU.txt) dosyasına
bakın.

## Hızlı başlangıç

```
pip install -r requirements.txt
python VERITAS_TBDY2018_Olcekleme.py
```

`fonts/` klasörü, uygulamanın kullandığı Inter yazı tipi dosyalarını içerir
ve `.py` dosyasıyla aynı dizinde kalmalıdır; klasör bulunamazsa uygulama
sistem yazı tipleriyle çalışmaya devam eder.
